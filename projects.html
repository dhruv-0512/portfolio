dvara
Malicious URL detection via Bloom Filter — Published PyPI package using probabilistic data structures for high-performance security threat indexing.
  • Indexed 268K+ threat URLs (URLhaus, PhishTank, OpenPhish, CERT Polska) into a 5.14MB Bloom Filter sized for 3M URLs at 0.1% target FPR (1/100th memory of a hash set).
  • Designed two-stage lookup pipeline (~0.003ms Bloom check, 145K URLs/sec throughput, PostgreSQL confirmation only on hits) validated to 0 false negatives & 0 false positives across 100K test URLs.
  • Self-hosted full stack (FastAPI, PostgreSQL, Redis) on AWS EC2 via Docker Compose.
